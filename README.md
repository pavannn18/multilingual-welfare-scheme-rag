# NLP-Based Multilingual Retrieval-Augmented Generation System for Government Welfare Scheme Recommendation

## Overview

This project develops a multilingual Retrieval-Augmented Generation (RAG) system to help users identify relevant government welfare schemes based on their personal profiles and eligibility criteria.

The system combines natural language processing, semantic retrieval, and eligibility-aware ranking to improve the discovery of relevant government schemes.

## Objectives

- Recommend relevant government welfare schemes based on user profiles.
- Support multilingual queries in English, Hindi, and Telugu.
- Use semantic retrieval to improve matching beyond keyword-based search.
- Compare the proposed approach with BM25 and Hybrid retrieval baselines.
- Present relevant scheme information and supporting evidence.

## Key Features

- Multilingual semantic retrieval
- User-profile-based scheme recommendation
- Eligibility-aware ranking
- Retrieval algorithm comparison
- Evaluation metrics including Accuracy@1, Accuracy@3, and Mean Reciprocal Rank (MRR)
- Dashboard for project interaction and results visualization
